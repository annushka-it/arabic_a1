# Карточки — арабский A1

Офлайн-тренажёр словаря арабского языка уровня A1 (CEFR) с переводом на русский.
414 слов в 11 категориях, интервальное повторение по системе Лейтнера.

Статическая страница без сервера и без сборки: открывается сразу, работает офлайн,
устанавливается на телефон как приложение.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика и сам словарь |
| `fonts/naskh.woff2` | Noto Naskh Arabic, урезанный до арабских глиф (45 КБ) |
| `fonts/OFL.txt` | лицензия шрифта (SIL Open Font License 1.1) |
| `manifest.webmanifest` | имя, иконки и цвета для установки на устройство |
| `sw.js` | service worker: кэширует файлы, даёт офлайн-режим |
| `icon-192.png`, `icon-512.png` | иконки приложения |

## Как опубликовать

Подойдёт любой статический хостинг. Два простых варианта:

**Netlify Drop** — без аккаунта и без консоли.
Зайти на app.netlify.com/drop и перетащить туда папку целиком.
Через пару секунд появится постоянная ссылка вида `имя.netlify.app`.

**GitHub Pages** — если нужен контроль версий.
1. Создать публичный репозиторий.
2. Загрузить содержимое папки в корень (кнопка «Add file» → «Upload files»).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту адрес будет `https://<логин>.github.io/<репозиторий>/`.

Важно: службы воркеров работают только по `https://` (или на `localhost`).
С двойным кликом по `index.html` на диске приложение откроется и будет работать,
но офлайн-кэш и установка на домашний экран не включатся.

## Как проверить локально

```bash
cd dist
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как установить на телефон

- **iPhone**: открыть ссылку в Safari → «Поделиться» → «На экран "Домой"».
- **Android**: открыть ссылку в Chrome → меню ⋮ → «Установить приложение».

После установки интернет больше не нужен. Прогресс хранится в браузере
устройства (`localStorage`), между устройствами не синхронизируется —
у каждого, кто откроет ссылку, своя статистика.

## Как обновить словарь

Словарь лежит прямо в `index.html` — строка `const CARDS = [...]`.
Формат одной карточки:

```json
{"id":"NOU0","c":"Существительные","a":"كِتابة","r":"письмо, писание","e":"writing"}
```

`a` — арабское слово, `r` — русский перевод, `e` — английский (показывается
мелким шрифтом под ответом), `c` — категория, `id` — любой уникальный ключ
(по нему хранится прогресс, так что менять его у существующих слов не стоит).

После правок поднять `VERSION` в `sw.js` — иначе у тех, кто уже открывал
приложение, останется закэшированная старая версия.
